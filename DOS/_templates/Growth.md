## Conventions — the rubric, so the next prune is cheap

**Entry test: what mechanism enforces this?** A rule that must fire repeatedly mid-task cannot
be enforced by louder prose. If the only mechanism available is "remember it", the item does
not enter.

Every item is exactly one class:

- **🎯 PRACTISE** — a behaviour to change. **Needs a named venue and a cadence.** Max 5.
- **📌 REMINDER** — no behaviour to change, just needs to be visible. **Needs a physical
  placement.** Max 3.
- **📄 ARTEFACT** — belongs in a doc, template or person file. **Move it and delete the line here.**
- **🪤 TRIP-WIRE** — only actionable on a named event. **Goes to `Standing Brief.md § Trip-wires`.**
- **✅ GRADUATED / ⛔ NOT MINE** — **delete.** Graduation is declared, not decayed: quiet means it
  never got a rep, not that it became a habit. Git keeps the history.

**Caps:** PRACTISE 5 · REMINDER 3 · Reading Active 2 · **whole file ≤6,000 chars.**

**No `## Reflections` section, deliberately.** It was 60% of the pre-prune file and nothing in it
was actionable. A distilled lesson that isn't one of the five classes above goes nowhere — the
journal already holds it, dated.

**Reviewed monthly inside `/weekly-scan`:** for each PRACTISE item, did its venue happen, and did
the behaviour get a rep? Feedback received from a named person lives on *that person's* file, not
here.
